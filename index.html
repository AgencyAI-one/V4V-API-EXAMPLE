LAB generation

POST /lab — the form is built from the input_schema / parameters_schema of the selected model. A field may go in input or parameters, never both; unknown fields are rejected. Models with selectable versions expose parameters.variant — use the values and defaults returned by discovery. project_name sets the title in Projects and, for LAB, Old runs; changing it under the same Idempotency-Key is a conflict, just like changing the inputs.

Tasks

GET /tasks/{task_id} — state is tracked solely by status: queued / processing → loading indicator; completed → files in results; failed → check error; cancelled is terminal too. Result links are signed and expire; fetch the task again to refresh them.
